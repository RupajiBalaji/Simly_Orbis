# Simly Orbis — Help Centre FAQ (P10)

### 1. I can't join a class ("Class code not found" or "Expired")
- Check that you typed the 6-character code without extra characters (hyphens/spaces are ignored automatically).
- Ask your teacher to check `/teacher.html` and click **Reset Join Code** if the previous code expired.

### 2. My nickname was rejected or "already taken"
- **Already taken (409):** Another student in the same class already picked that nickname. Add a number (e.g. `Curie_02`).
- **Rejected (400):** Nicknames must be 2–24 characters using letters, numbers, spaces, `.`, `_`, or `-`, and must not contain email addresses, phone numbers, URLs, or profanity.

### 3. Why can't I submit an assignment?
- You must **finish** the lab session first so the server generates your verified lab report.
- Make sure the finished **Session ID** matches the experiment required by the assignment, belongs to you, and hasn't already been submitted.

### 4. Does the microphone button record my voice?
- **Orbis never receives or stores audio.** When you click the mic button, your browser's speech recognition engine handles the audio (in Chrome, this is processed by Google's servers). You can always type instead.

### 5. How does a teacher reset a join code or delete class data?
- Open `/teacher.html`, select the class under **Your Classes**, and click **Reset Join Code** (invalidates the old code immediately) or **Delete Class & Data** (permanently deletes the class, roster, assignments, submissions, and student tokens).

### 6. Is Simly Orbis medical or flight-engineering advice?
- **No.** Simly Orbis is strictly an educational simulation. Literature reference tables are unverified by human domain experts until signed off in `docs/EVIDENCE_PACK.md`.
