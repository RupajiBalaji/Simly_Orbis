# Simly Orbis — User Test Script & Feedback Form (P10)

## 5 Guided Tasks for a 15-Minute User Test
1. **Task 1 — Join a Class (`/student.html`):** Enter the test join code and choose a nickname (e.g. `Curie_07`). Note whether any error messages are clear.
2. **Task 2 — Start & Complete PPE + First Step (`/index.html`):** Launch **Oral PK Ward** (`pk_ward`), dismiss/complete onboarding if shown, put on PPE (`wear_ppe`), and perform the first protocol step using the primary action button.
3. **Task 3 — Ask Orbis & Dr. Orbis:** Type a lab command in **Ask Orbis** (e.g. `tare balance`) and request a hint from **Dr. Orbis**. Note whether typing or voice fallback feels clear.
4. **Task 4 — Finish & Submit Assignment:** Complete or finish the session, copy/note the Session ID, and submit it on `/student.html` under **Assignments**.
5. **Task 5 — Teacher Review (`/teacher.html`):** On the teacher dashboard, check **Roster**, **Submissions**, **Class Analytics**, and download **Export CSV**.
